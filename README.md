# דירוג טקסט קצר

שאילתה מול כמה שורות. הציון הוא קוסינוס של TF-IDF. Jaccard על קבוצת המילים הוא הבייסליין, בלי ספירת חזרות ובלי נדירות.

מילה היא רצף של אותיות עבריות או לטיניות. אין חיתוך תחיליות: `חתול` לא פוגש את `החתול`.

```
query=alpha alpha beta
0  cosine=0.818  jaccard=0.500
1  cosine=0.731  jaccard=0.667
```

השורה עם שלוש פעמים `alpha` מנצחת בקוסינוס. Jaccard מעדיף את השורה השנייה, כי יש בה שני טיפוסים משותפים מתוך שלושה.

```
query=החתול ישן
0  cosine=0.707  jaccard=0.500
1  cosine=0.000  jaccard=0.000
```
