# דירוג טקסט קצר

שאילתה מול כמה שורות. הציון הוא קוסינוס של TF-IDF. Jaccard על קבוצת המילים הוא הבייסליין, בלי ספירת חזרות ובלי נדירות. Dice על טריגרמים של תווים מגשר כשהמילה והצורה עם ה׳ הידיעה לא זהות. Overlap שואל איזה חלק מהקבוצה הקצרה נמצא בארוכה.

מילה היא רצף של אותיות עבריות או לטיניות. אין חיתוך תחיליות: `חתול` מול `החתול ישן` נשאר 0 בקוסינוס, ו-Dice יוצא 0.667.

```
query=alpha alpha beta
0  cosine=0.818  jaccard=0.500  dice=0.750  overlap=1.000
1  cosine=0.731  jaccard=0.667  dice=0.769  overlap=1.000
```

השורה עם שלוש פעמים `alpha` מנצחת בקוסינוס. Jaccard מעדיף את השורה השנייה, כי יש בה שני טיפוסים משותפים מתוך שלושה.

```
query=החתול ישן
0  cosine=0.707  jaccard=0.500  dice=0.667  overlap=1.000
1  cosine=0.000  jaccard=0.000  dice=0.000  overlap=0.000
```
